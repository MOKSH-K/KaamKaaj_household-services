# KaamKaaj 🏠

**Your Home. Our Help.**

KaamKaaj is a household services platform that connects families with trusted, verified workers for everyday home tasks — cleaning, laundry, kitchen help, and more.

## What Makes KaamKaaj Different

Most household service apps make you book a slot and wait. KaamKaaj works the other way around:

1. You raise a request for a service
2. Every available worker nearby is notified instantly
3. Whoever is free accepts and heads to you right away — no scheduling, no waiting

This is an **on-demand, instant-matching** model, not an advance-booking one.

## Current Coverage

KaamKaaj is currently live on a small scale in:

- Doddabommasandra
- Yelahanka

More areas will be added as the worker base grows.

> **Note:** The platform is currently built for **apartment complexes only**, not standalone independent houses. This helps with worker verification and coordinating access with building security.

### For Workers

- Safe and secure platform

## Pricing Model

KaamKaaj uses a **fixed price per service, tiered by apartment size (1BHK / 2BHK / 3BHK+)**, with an **optional tip** shown to the customer after a job is completed. This keeps pricing transparent and trustworthy for an instant-matching flow, while still giving workers an incentive for great service.

## Tech Stack

- **HTML5 / CSS3** — no frontend framework, hand-built pages
- **Vanilla JavaScript** — interactivity (modals, search, instant-match simulation, scroll animations)
- **Google Fonts** — Inter
- **Font Awesome 6.5.2** (via CDN) — icons
- **SVG** — logo assets (green and navy variants for light/dark backgrounds)
